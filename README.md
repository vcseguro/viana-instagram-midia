# Viana do Castelo Seguros — mídia do Instagram

Repositório **público** só com as imagens e os vídeos dos posts do Instagram e do Facebook (@vianadocasteloseguros).
O Metricool baixa os arquivos daqui pelo link `raw.githubusercontent.com` na hora do agendamento.

- Uma pasta por semana: `AAAA-MM-DD-semana-N/` (data da terça em que a semana começa).
- Só entra aqui o que já foi aprovado para publicação. Nada de dados de clientes, planilhas ou documentos internos.
- Planejamento, legendas e instruções ficam no repositório privado `corretora-gestao` (`docs/marketing-instagram/`).
